## The critic does not receive the accumulated iteration feedback

Status: Implementation issue · Checked: 2026-09-26

The public code appends feedback to the conversation history, but the actual API call sends only the initial prompts. This does not establish that the paper’s experiments used the same defective version.

### Reviewed material

IJCAI 2025 paper Section 3.4; LPFG commit 6bc2be0dcd639600123f826f687288d164f3f975, LPFG.py lines 253-269.

### Observed evidence

The code appends generated features and the next feedback request to mssa_optimizer. The actual critic API call passes messages containing only the initial sys_optimizer and prt_optimizer prompts; the accumulated conversation is not included.

### Reason for flagging

Appending feedback to a local history does not send it to the critic. This public request path cannot condition the critic on the accumulated generated features as described by the iterative feedback mechanism.

### Scope and author response

The generator retains its own context, so this is not a claim that all iteration is absent. The review did not establish that this released commit produced the publication results. No API calls or model runs were made.

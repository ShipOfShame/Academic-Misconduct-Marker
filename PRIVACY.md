# Privacy

The extension processes author names, titles, paper URLs, and author-specific identifiers visible on supported arXiv/Scholar pages locally. It stores settings and explicitly imported evidence in Chrome local storage.

It has no analytics, telemetry, advertising, remote inference, remote executable code, or automatic database fetch. Page contents are not uploaded by the extension. Clicking a paper or evidence link opens that website through normal browser navigation; the destination has its own privacy practices.

Exported evidence files are user-controlled local downloads. Removing the extension removes Chrome's extension-local storage. The public repository contains professional identity sources and academic evidence summaries; it excludes local research snapshots and private contact records.

## Public evidence website

The GitHub Pages site uses no analytics, external fonts, or third-party scripts. It fetches its evidence snapshot from the same site. Search and scoring adjustments run in the current tab and are not sent to the maintainers or saved in browser storage. GitHub operates the hosting service and may process access logs under its own policies. Following a source link opens that external service.

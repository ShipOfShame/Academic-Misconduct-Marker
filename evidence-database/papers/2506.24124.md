## The PEMS07 Avg row is inconsistent with its four component values

Status: Reporting discrepancy · Checked: 2026-09-26

In v2 Table 10, the four TimesCLIP MSE values average 0.08975, but the table reports 0.358. The MAE values average 0.193, but the table reports 0.773. This supports an aggregation or labeling error, not a finding that the experimental data were fabricated.

### Reviewed material

arXiv 2506.24124v2, Table 10 (PEMS07; horizons 12, 24, 48, 96) and Table 2.

### Observed evidence

The four TimesCLIP MSE values are 0.063, 0.074, 0.106, 0.116: (0.063 + 0.074 + 0.106 + 0.116) / 4 = 0.08975, versus reported Avg 0.358. The MAE values 0.175, 0.183, 0.204, 0.210 average 0.193, versus reported Avg 0.773. The reported averages even exceed every component in their respective columns. Table 2 reuses these aggregates.

### Reason for flagging

An average with nonnegative weights cannot exceed all its components. Rounding cannot reconcile these values. The table therefore contains an aggregation or labeling error affecting the interpretation of the reported absolute errors.

### Scope and author response

The aggregate values are close to sums rather than means; other methods show a similar pattern. A shared scaling error could leave the within-dataset ranking unchanged. The table inconsistency does not demonstrate that the component results were invented.

- [Paper v2](https://arxiv.org/abs/2506.24124v2) — Tables 10 and 2: PEMS07 MSE/MAE aggregates

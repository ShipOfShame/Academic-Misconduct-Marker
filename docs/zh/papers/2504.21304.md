## 评论者未收到累积的迭代反馈

状态：实现问题 · 核查日期：2026-09-26

公开代码把反馈追加到对话历史中，但评论者 API 调用只发送初始提示。累积反馈没有传入评论者请求。

### 核查材料与版本

IJCAI 2025 论文第 3.4 节；LPFG 提交 6bc2be0dcd639600123f826f687288d164f3f975，LPFG.py 第 253–269 行。

### 观察到的证据

代码将生成的特征和下一轮反馈请求追加到 mssa_optimizer。但实际评论者 API 调用的 messages 只包含初始 sys_optimizer 与 prt_optimizer，没有发送累积对话。

### 标记理由

向本地历史列表追加反馈，并不意味着评论者已收到反馈。该公开请求路径不能按所述迭代反馈机制，让评论者基于累积的生成特征进行回应。

### 相关情况与作者回应

生成器保留了自身上下文。本条问题位于所引公开提交的评论者请求路径：本地追加的历史没有进入 messages 参数。

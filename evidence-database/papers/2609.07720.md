## The visual judge is asked to compare identity without the reference images

Status: Implementation issue · Checked: 2026-09-26

Character reference images reach the image generator, but the keyframe judge receives only the generated image and a boolean flag. The flag adds text asking the judge to compare against reference sheets that are not attached. The clip judge receives only frames from the current clip.

### Reviewed material

arXiv 2609.07720v1; CineCrew commit 9a00efa7db65ba028c1523907f6cee844776123a

### Observed evidence

Character reference images reach the image generator, but the keyframe judge receives only the generated image and a boolean flag. The flag adds text asking the judge to compare against reference sheets that are not attached. The clip judge receives only frames from the current clip.

### Reason for flagging

Textual appearance descriptions do not supply the missing reference pixels. The public visual-review path lacks direct image comparison with the designated identity reference or adjacent generated clips, despite the identity and continuity review described in Section 3.4.

### Scope and author response

This finding concerns the production visual judge and its message payload.

## A final rejection can associate media with an unexecuted revised prompt

Status: Implementation issue · Checked: 2026-09-26

After a rejected attempt, both the keyframe and clip loops update the prompt even on the last permitted attempt. The pipeline then saves that revised prompt together with the media generated before the revision.

### Reviewed material

arXiv 2609.07720v1; CineCrew commit 9a00efa7db65ba028c1523907f6cee844776123a

### Observed evidence

After a rejected attempt, both the keyframe and clip loops update the prompt even on the last permitted attempt. The pipeline then saves that revised prompt together with the media generated before the revision.

### Reason for flagging

With max_retries=0, prompt P0 produces image I0; rejection supplies P1; the saved image remains I0 while the final prompt becomes P1. The same mismatch occurs when the last attempt of a longer retry loop is rejected. Final FilmDSL and VideoJob fields can therefore misstate the generation conditions.

### Scope and author response

The path requires a final rejected attempt with a nonempty revised_prompt; it is established by static control-flow analysis.

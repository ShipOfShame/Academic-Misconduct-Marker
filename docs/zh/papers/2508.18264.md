## README 与论文报告的性能指标不一致

状态：报告不一致 · 核查日期：2026-09-26

固定版本 README 声称使用四个视觉 token 时 F1 为 87.7%，但 arXiv v2 表 21 报告的 F1 为 74.84。摘要中的性能保留率也与表格数值计算出的比率不同。

### 核查材料与版本

MMTok README 提交 8e2686836ed5bbe05d064f1d1c20e50c73c70b94；arXiv 2508.18264v2 的摘要与表 21。

### 观察到的证据

README 将四个视觉 token 的表现描述为 87.7% F1。表 21 中，四 token 的 POPE F1 为 74.84，完整模型为 85.9，两者之比约为 87.12%。摘要则将 87.7% 描述为保留的相对性能，而非绝对 F1。

### 标记理由

绝对 F1 与相对基线的性能保留率是不同的量。若没有指标或实验版本的说明，这些公开描述不能被视为同一实验设置下一致的性能报告。

### 相关情况与作者回应

本条对照固定 README 与 arXiv v2。README 使用绝对 F1，摘要使用相对性能保留率，表 21 提供四 token 和完整模型的 F1 数值。

## 排除填充区域后，选择器仍可能反复选取被排除的 token

状态：实现问题 · 核查日期：2026-09-26

选择器只按全部 token 数量限制选择预算，没有减去被排除的填充 token。有效候选耗尽后，剩余循环会对全部为负无穷的得分取 argmax，反复选择索引 0。

### 核查材料与版本

MMTok 提交 8e2686836ed5bbe05d064f1d1c20e50c73c70b94；LLaVA-1.5 的 tensor 输入路径，启用填充排除，覆盖得分有限且选择预算超过有效候选数。

### 观察到的证据

选择器只按全部 token 数量限制选择预算，没有减去被排除的填充 token。有效候选耗尽后，剩余循环会对全部为负无穷的得分取 argmax，反复选择索引 0。

### 标记理由

以 1008×336 图像为例，公开填充规则在 24×24 网格中排除顶部八行和底部八行，仅剩 192 个有效 token。使用 README 的 256 个 token 预算并启用填充排除时，前 192 轮用完有效候选，随后 64 轮重复选择已被排除的索引 0。结果既含填充 token，也不是由 256 个不同 token 构成的子集。

### 相关情况与作者回应

结论来自填充尺寸计算和循环控制流分析，未测量论文各项基准中出现此输入条件的频率。

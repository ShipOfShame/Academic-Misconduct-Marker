## The equation and public code use opposite update signs

Status: Reporting discrepancy · Checked: 2026-09-26

AAAI 2026 Equation (2) adds the gradient, while the pinned code subtracts it. The equation and released code specify opposite update directions. This discrepancy is not evidence of data fabrication.

### Reviewed material

AAAI 2026 publication, Equation (2), PDF page 4 / printed page 33695; Lateng-Reasoning commit 94e70c46acb39c45c713d010d53f9e06421527d8.

### Observed evidence

Equation (2) specifies h_new = h + eta * gradient[L], where L = MSE(h_good, h) - MSE(h_bad, h). The released coconut_search.py computes that loss but updates h by subtracting learning_rate * gradient[L].

### Reason for flagging

For positive step sizes the displayed equation and code move in opposite directions on the same objective. A reader implementing the stated method would not reproduce the released update rule.

### Scope and author response

This identifies a paper/code specification mismatch; it does not establish which rule generated the reported results. The code refines embeddings without updating model parameters. No fabrication or individual intent is inferred.

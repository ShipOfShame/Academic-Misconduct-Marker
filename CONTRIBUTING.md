# Contributing

Contributions should improve specific evidence records, identity resolution, accessibility, or extension behavior. Use English for code comments, documentation, UI, issue reports, and evidence summaries. Link original-language sources where necessary, while describing their significance in English.

For evidence changes, follow [data maintenance](docs/data-maintenance.md). For identity corrections, provide an institutional/personal source that connects the person to the particular paper or identifier. Never infer wrongdoing solely from coauthorship or a same-name search result.

For code changes, explain the user-visible problem and add a regression test when behavior changes. Run `npm run check` and the relevant browser tests. Do not commit `node_modules`, local research snapshots, credentials, account data, or generated ZIPs.

Keep discussion focused on records and behavior. Personal abuse, speculative biographies, and campaigns directed at individuals do not belong here.

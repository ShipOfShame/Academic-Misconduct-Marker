## The experimental R-squared denominator uses predictions

Status: Reporting discrepancy · Checked: 2026-09-26

Section 4.1 and Appendix B put predicted values in the total-sum-of-squares denominator. Equation 2 uses true values, as does the standard definition.

### Reviewed material

arXiv 2505.15572v1; related public repository Data2Eqn-RL, commit 4e27dd98f011963511cda60af4caadbfdc24e755

### Observed evidence

Section 4.1 and Appendix B put predicted values in the total-sum-of-squares denominator. Equation 2 uses true values, as does the standard definition.

### Reason for flagging

These formulas differ: true values [0,2] and predictions [0,1] give standard R-squared 0.5 but the printed experimental formula gives 0.

### Scope and author response

The related repository calls r2_score with true and predicted labels; this finding concerns the printed formula.

## Complete original model cards were not released

Status: Missing materials · Checked: 2026-09-26

An author explicitly stated that the full model cards could not be disclosed. Scraping current pages and generating new descriptions cannot reconstruct the original manual annotations. Code and some data are public.

### Reviewed material

MLLM-Tool paper Section 3.1 and issue #6 author comment, reviewed September 26, 2026.

### Observed evidence

The paper describes model cards for 932 models. The author states that the complete cards cannot be disclosed, supplies model lists and function categories, and suggests scraping current model pages and generating replacement descriptions. The reply explains that the original descriptions were primarily manually annotated and that some model pages may no longer be accessible.

### Reason for flagging

Current scraped pages and newly generated descriptions cannot reconstruct the original annotations used to construct the research data. This is an author-confirmed gap in the materials required to trace that construction process.

### Scope and author response

Code and some data are public; issue #7 also contains a response identifying test materials. The disclosed restrictions may have legitimate reasons. This record does not claim that all data are unavailable, that a specific venue rule was breached, or that the data were fabricated.

## The released test set contains 184 inputs already present in training

Status: Implementation issue · Checked: 2026-09-26

Exact comparison of the 2,397 test records with 44,533 training records finds 184 distinct repeated inputs: 131 text, 50 audio and 3 video. Of these, 173 have at least one accepted test answer already attached to the same input in training, and 159 have every accepted answer represented there.

### Reviewed material

WACV 2025 paper, Section 3.4 and Table 2; released data and loaders at commit 8b74aad63ac511f6cbd7a74fb12aceee33975cf8; exact JSON comparison on September 26, 2026.

### Observed evidence

Exact comparison of the 2,397 test records with 44,533 training records finds 184 distinct repeated inputs: 131 text, 50 audio and 3 video. Of these, 173 have at least one accepted test answer already attached to the same input in training, and 159 have every accepted answer represented there.

### Reason for flagging

The matching key is the unmodified query string, input modality and all media path fields. Training and inference code select these files, and the author identifies inference.py as the test-set entry point in issue #7. Closed-set reuse of API labels does not require reusing the same query and media reference across training and testing. The released evaluation split therefore includes seen examples rather than an entirely held-out set.

### Scope and author response

Media equality is established at the path-reference level. The counts describe the released split; the effect on reported model accuracy was not measured.

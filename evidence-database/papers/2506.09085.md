## The postfix search-space claim confuses token vocabulary with complete sequences

Status: Reporting discrepancy · Checked: 2026-09-26

Appendix A attributes a reduction from an exponential search space to |C| = |O| + |X|D + 3 to postfix notation. The expression adds operator, feature and special-token counts; it does not count complete transformation sequences.

### Reviewed material

arXiv 2506.09085v1, Appendix A and Figure 7; the counterexample respects the prompt limit on the number of feature combinations.

### Observed evidence

Appendix A attributes a reduction from an exponential search space to |C| = |O| + |X|D + 3 to postfix notation. The expression adds operator, feature and special-token counts; it does not count complete transformation sequences.

### Reason for flagging

Even under the prompt in Figure 7, take k distinct features with k below 50 and select either sin or tanh for each. This gives 2^k valid feature sets while the token vocabulary stays fixed for those features. Infix-to-postfix conversion also preserves each represented expression. Removing brackets therefore does not establish the claimed sequence-space bound.

### Scope and author response

The reviewed manuscript is arXiv 2506.09085v1.

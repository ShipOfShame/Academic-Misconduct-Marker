Status: Implementation issue · Checked: 2026-09-26

The evaluation entry enables post-processing only for WER. The other five metric processes reload the original JSON without that option; the WER process does not save its modified text.

### Reviewed material

arXiv 2601.21347v1; SAP-Hypo5 commit 5d37b96fd25a3e612ba9a4c04d44de4446f5d3fe

The evaluation entry enables post-processing only for WER. The other five metric processes reload the original JSON without that option; the WER process does not save its modified text.

### Reason for flagging

When post-processing changes content, the metrics measure different transcripts. Cross-metric differences then include a processing difference rather than only metric sensitivity.

## Digit deletion removes numerical errors before scoring

Status: Implementation issue · Checked: 2026-09-26

inference.py deletes all digits from references and baseline hypotheses, and from model output under default options. Those cleaned strings are saved for all later metrics. For example, take 5 pills daily and take 9 pills daily both become take pills daily.

### Reviewed material

arXiv 2601.21347v1; SAP-Hypo5 commit 5d37b96fd25a3e612ba9a4c04d44de4446f5d3fe

### Observed evidence

inference.py deletes all digits from references and baseline hypotheses, and from model output under default options. Those cleaned strings are saved for all later metrics. For example, take 5 pills daily and take 9 pills daily both become take pills daily.

### Reason for flagging

A numerical substitution can disappear from both WER and semantic evaluation. Cleaning the baseline can also move number-error cases into the NoErr group, despite the paper emphasis on preserving numbers.

### Scope and author response

This is a constructed static counterexample; the incidence and score impact on actual samples were not measured.

## Released repetition handling differs from Algorithm 1

Status: Implementation issue · Checked: 2026-09-26

Algorithm 1 truncates the transcript at the first occurrence of the selected repeated phrase. The code selectively compresses runs while preserving later content, and retains short non-tail runs of up to three repeats.

### Reviewed material

arXiv 2601.21347v1; SAP-Hypo5 commit 5d37b96fd25a3e612ba9a4c04d44de4446f5d3fe

### Observed evidence

Algorithm 1 truncates the transcript at the first occurrence of the selected repeated phrase. The code selectively compresses runs while preserving later content, and retains short non-tail runs of up to three repeats.

### Reason for flagging

With single-word phrases allowed, go go home becomes go under the paper rule but remains go go home under the code. The two rules can produce different content and evaluation scores.

### Scope and author response

Comparison of the published pseudocode and this fixed implementation.

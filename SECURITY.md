# Security

For a security vulnerability, use GitHub's private vulnerability reporting if it is available on this repository. Otherwise open an issue requesting a private contact channel without including exploit details or sensitive data. Evidence corrections and identity mismatches should use the ordinary issue templates.

Imported data is untrusted. Rendering uses text nodes, sources require HTTPS, identifiers are validated, and automatic identity matching rejects conflicting IDs. The extension requests only local storage and statically injects scripts on supported hosts. The test suite includes markup-injection, hostile-URL, and ID-conflict cases.

Only the latest release is actively maintained. No formal security audit has been completed. Do not submit tokens, private browser profiles, or unpublished documents in public reports.

## Signed similarities let the Viterbi branch return a backward label path

Status: Implementation issue · Checked: 2026-09-26

The Viterbi branch uses raw cosine similarities as emission probabilities. Negative path scores can lose to a forbidden transition whose score is zero, allowing a decreasing label sequence.

### Reviewed material

CVPR 2023 paper; arXiv 2303.12370v2; WeakSVR commit 0caa9eb05ff77f8798167a8ad754e90f3a059af2

### Observed evidence

The Viterbi branch uses raw cosine similarities as emission probabilities. Negative path scores can lose to a forbidden transition whose score is zero, allowing a decreasing label sequence.

### Reason for flagging

For two frames with similarity rows [-a,-a] and [a,a], a>0, the upper-triangular transition matrix and uniform prior produce initial scores [-a/2,-a/2]. The second-frame scores are [0,-a²/4]; backtracking returns [1,0]. This contradicts the temporal-order constraint in Section 3.4.

### Scope and author response

The counterexample is derived from the Viterbi option. The default command-line option is sorting.

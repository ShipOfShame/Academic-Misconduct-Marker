## The feature-selection state transition always returns the original set

Status: Reporting discrepancy · Checked: 2026-09-26

Section 5.1 defines the next state as the union of the current feature set and a subset drawn from that same set.

### Reviewed material

Published version: ACM TKDD 20(5), Article 71, DOI 10.1145/3801742; supplied PDF SHA-256 5296d704001f426f37f5911e013972eeaba318a1ee822b82c29fb1835cbe7289.

### Observed evidence

Section 5.1 defines the next state as the union of the current feature set and a subset drawn from that same set.

### Reason for flagging

The union equals the original set for every action. It cannot remove a feature or add a feature outside the current set, so it cannot represent the described feature-selection transition.

### Scope and author response

Survey formalization in the published version; the same expression occurs in arXiv v1.

## iTGA natural-growth search is classified as embedded tree-model selection

Status: Reporting discrepancy · Checked: 2026-09-26

Section 3.1.3 and Figure 2 place reference 208 under embedded tree-based methods. The original iTGA article defines a population-based metaheuristic whose natural trees represent candidate solutions, with binary vectors for feature selection.

### Reviewed material

Published version: ACM TKDD 20(5), Article 71, DOI 10.1145/3801742; supplied PDF SHA-256 5296d704001f426f37f5911e013972eeaba318a1ee822b82c29fb1835cbe7289.

### Observed evidence

Section 3.1.3 and Figure 2 place reference 208 under embedded tree-based methods. The original iTGA article defines a population-based metaheuristic whose natural trees represent candidate solutions, with binary vectors for feature selection.

### Reason for flagging

The survey conflates a tree-growth search metaphor with a predictive tree model and a tree representation of feature subsets.

### Scope and author response

Reference 208 was checked against the primary article; this finding concerns that specific classification.
